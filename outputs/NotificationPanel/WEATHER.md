# Погода и минимальный экран — 0.6.0

В панели убраны видимые заголовки «Уведомления» / «По приложениям», общий счётчик и пояснение пустого состояния. При отсутствии карточек остаются часы, дата, погода и настройки. Сообщения о необходимом доступе или отключённой службе сохранены, чтобы можно было восстановить работу. Карточки уведомлений остаются. Общий счётчик доступен средствам доступности без видимой строки. Виджет этим изменением не затронут.

Нажмите «—°» справа от часов, затем «Разрешить». Android запросит только ACCESS_COARSE_LOCATION (приблизительное местоположение). Фоновое местоположение и точные координаты не запрашиваются. При отказе панель продолжает работать без температуры. Если разрешение запрещено окончательно, включите его в системных настройках приложения.

Данные: [Open-Meteo](https://open-meteo.com/), [документация](https://open-meteo.com/en/docs). Бесплатный API для некоммерческого использования, данные CC BY 4.0. Это текущая оценка температуры воздуха погодной моделью, не измерение датчиком телефона. Атрибуция находится рядом с температурой; по нажатию доступны сведения и ссылка на источник.

При открытой панели получение координат и запрос погоды выполняются примерно раз в 15 минут. Сервис получает IP и координаты, округлённые до двух десятичных знаков (около километра по широте). Содержимое уведомлений не передаётся. Координаты и история погоды не записываются на диск. Кэш температуры хранится в памяти; после 30 минут без успешного обновления вместо старого значения отображается «—°». После ухода с экрана ожидание геолокации прекращается, поздние сетевые ответы не меняют интерфейс. Уже начатый HTTPS-запрос может завершиться в фоне.

При отключённой геолокации, отсутствии подходящего источника или сети — «—°» либо ещё свежий кэш. Нажмите температуру для причины и повторной попытки. Для подключения требуется работа системного поставщика приблизительного местоположения; если OxygenOS его не предоставляет, появится сообщение об отсутствии координат.

## Название места — 0.6.1
Под температурой показывается город, район или регион, определённый системным Android Geocoder по округлённым координатам того же погодного запроса. Системный поставщик геокодирования может обращаться в сеть. Если названия нет, показываются координаты; чужой город не подставляется. Полная подпись и источник Open-Meteo / CC BY 4.0 доступны по нажатию. На AOSP проверен резервный вариант с координатами, выбор города/района проверен искусственными Address. Реальный Geocoder OxygenOS нужно проверить на телефоне.
