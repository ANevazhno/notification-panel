# Панель уведомлений — прототип 0.6.1

Бесплатный локальный Android-прототип для проверки группировки уведомлений по приложениям на OnePlus 13s / OxygenOS 16. Android 9+; собран с targetSdk 36 (Android 16). Проверен на Android 16 AOSP в эмуляторе; пользователь подтвердил работу экрана 0.2.0 на OnePlus.

## Установка и первый запуск

1. Перенесите `NotificationPanel-0.6.1.apk` на телефон и установите вручную. Разрешение установки APK, если Android запросит его, выдаёт пользователь.
2. Откройте приложение «Панель уведомлений».
3. Нажмите «Открыть доступ к уведомлениям». В системном списке найдите «Панель уведомлений» и самостоятельно включите доступ.
4. Вернитесь в панель. Если соединение не установилось, нажмите «Переподключить».
5. Для быстрого открытия: «Настройки → Добавить плитку быстрых настроек», затем подтвердите системный диалог. Также работает обычный ярлык приложения.

Если Android блокирует выдачу доступа из-за ограниченных настроек установленного APK, панель не обходит ограничение. Пользователь должен самостоятельно решить, доверяет ли он APK, и использовать доступный в своей сборке Android официальный способ разрешения доступа.

## Что работает в коде

В 0.2.0 обновлён внешний вид: часы и дата, атмосферный градиент, полупрозрачные поверхности, компактные стопки карточек и счётчики. В раскрытом виде «Открыть» и быстрый ответ стоят в одной строке; остальные действия доступны через «⋯». Для чата используется conversation title, если источник его предоставил. Поверхности имитируют матовое стекло; захват и размытие обоев или экрана не выполняются.

- Одна сворачиваемая секция на пару «профиль пользователя + package name».
- Обновления исходного notification key заменяют запись, а не добавляют дубликат.
- Summary не дублирует имеющиеся дочерние карточки, в том числе когда дочерние скрыты фильтром.
- Дочерние карточки открывают исходный PendingIntent. Если источник установил AUTO_CANCEL, после успешной отправки перехода запрашивается отмена исходного уведомления.
- Доступные действия источника показываются отдельными кнопками с подтверждением. Текстовый RemoteInput поддерживается; вложения и специальные формы ввода не реализованы.
- Исчезновение оригинала обновляет панель. Самостоятельно определить факт прочтения сообщения панель не может: она следует состоянию уведомлений Android.
- «Убрать уведомление…» отменяет оригинал только после подтверждения. Общей очистки нет.
- При изменении уведомления открытый старый диалог действия не отправляет устаревший PendingIntent: нужно открыть карточку заново.
- По умолчанию скрыты ongoing, foreground services, NO_CLEAR, звонки, будильники, навигация, медиа, Android и System UI.
- Исключения приложений; первые 3/5/10 карточек; «Ещё»; необязательное автосворачивание через 15 минут после раскрытия, пока панель открыта.
- Демонстрационный режим с вымышленными данными.

## Границы прототипа

Панель — отдельный экран, вызываемый ярлыком или плиткой. Она не заменяет жест системной шторки, не рисует плавающую кнопку и не меняет группировку OxygenOS. Оригиналы остаются в системной шторке. Это сохраняет возможность отслеживать обновления и удаления.

Счётчик показывает количество исходных карточек после исключения дублирующих summary, а не число писем/сообщений. Android или приложение могут скрывать текст. Bubbles, оригинальные RemoteViews, медиаинтерфейс, изображения, вложения и полная семантика conversations не воспроизводятся. При недоступном названии приложения показывается package name. Доступ к рабочему профилю зависит от политики устройства.

Успешная отправка PendingIntent подтверждает передачу действия Android, но не доставку ответа и не успешное открытие нужного экрана. Это проверяется на телефоне. Действия «Удалить», «Прочитано» и подобные выполняет исходное приложение. Панель не помечает сообщения прочитанными сама.

## Данные и разрешения

В манифест добавлены INTERNET и REQUEST_INSTALL_PACKAGES для обновлений по запросу пользователя. Нет доступа к общим файлам, контактам, SMS, Accessibility, наложениям или root. Нет рекламы, аналитики, сторонних библиотек и облачных сервисов. Панель хранит текст и PendingIntent только в памяти процесса; виджет передаёт краткий текст лаунчеру, который может его кэшировать; после перезапуска активные уведомления запрашиваются заново. На диск сохраняются настройки, исключённые package name/профили, адрес обновлений и загруженный APK в cache. Резервное копирование выключено.

Окно не показывается поверх блокировки, а при рендере проверяется разблокировка устройства. Панель не запрещает скриншоты и трансляцию, поэтому её интерфейс можно проверять через «Связь с телефоном»; конкретное поведение зависит от OxygenOS и разрешений трансляции.

## Сборка

Нужны JDK 17, `android.jar` Android SDK 36 и Android Build Tools 36.0.0. Gradle и Android Studio не обязательны.

```powershell
.\build.ps1 -JdkHome C:\tools\jdk-17 -AndroidJar C:\tools\android-36\android.jar -BuildTools C:\tools\build-tools\36.0.0 -WorkDir C:\work\panel-build -KeyStore C:\work\panel-dev.jks
```

Скрипт компилирует Java, запускает тесты GroupingTest, создаёт DEX, выравнивает APK, подписывает и проверяет подпись. Используйте пустую отдельную папку WorkDir для каждой сборки. APK появляется рядом с папкой проекта. Для обновления поверх установленной версии нужен тот же ключ подписи. Ключ текущей сборки хранится отдельно в рабочей папке, в исходный архив не входит. Это локальная тестовая подпись, не публикация Google Play.

## Выполненные проверки

- Компиляция всех классов против публичного Android SDK 36.
- JVM-тесты слияния разных групп, дедупликации обновлений, разделения профилей, summary, исключений, порядка и пустого состояния.
- Проверка структуры пакета и APK Signature Scheme v3.
- Верификация загруженного JDK по SHA-256 поставщика, SDK-архивов по контрольным суммам репозитория Google.

На Android 16 AOSP в официальном эмуляторе прошли 12 интеграционных проверок: подключение listener, пустое состояние, слияние групп, раскрытие, обновление текста без дубля, фильтры, удаление источником, передача RemoteInput в исходный PendingIntent и открытие тестового экрана. Результат — `../PanelTestStand/test-results.txt`. Плитка, настоящие Compass/Яндекс.Почта и OxygenOS пока не проверены. Чек-лист телефона — `TESTING.md`.

## Музыка — 0.11.13

Карточка над уведомлениями управляет активным плеером через Android MediaSession. Поддерживает обложку, название, исполнителя, предыдущий трек, паузу/продолжение и следующий трек. Доступность данных и команд зависит от плеера. На паузе карточка сохраняется; после остановки или завершения сеанса скрывается. Дополнительные разрешения не нужны при уже включённом доступе к уведомлениям.
