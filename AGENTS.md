# Контекст для следующего разработчика

Сначала прочитай HANDOFF.md, затем outputs/NotificationPanel/DESIGN.md,
TESTING.md, UPDATES.md, README.md, WIDGET.md и WEATHER.md.
Актуальная версия — в AndroidManifest.xml. Исторические записи о выпуске/проверках
не являются результатами нового прогона. Более поздние записи уточняют ранние.

Сохраняй текущий интерфейс и поведение; не перерабатывай соседние функции без задачи.
Не публикуй APK и не обновляй рабочий портал Spleta без поручения пользователя.
Не коммить ключи, cookies, токены, дампы уведомлений, SMS, снимки личных экранов.
Для новых APK поверх установленного приложения нужен исходный ключ подписи.
Не подменяй его автоматически созданным ключом и не удаляй приложение для обхода
несовпадения подписи: это удалит данные.
Обновляй HANDOFF.md при существенных изменениях контекста.
